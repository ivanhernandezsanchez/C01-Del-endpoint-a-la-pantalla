# EJERCICIO-08 · Muestra una lista de productos

## Qué he aprendido
He aprendido a recibir varios productos desde la API y presentarlos como una lista en React Native.

## Respuesta a la pregunta de comprensión
fetch() obtiene los productos, useState guarda la lista y FlatList muestra cada producto. Cada pieza tiene un trabajo distinto.

## Qué he modificado
He conectado GET /productos con la pantalla y he mostrado los productos recibidos en una lista.

## Resultado
Prueba primero GET /productos en el backend. Luego abre Expo y comprueba que aparezca una fila por producto. Para usar un móvil físico, la IP y el puerto de API_URL deben señalar al backend de este ejercicio.
