# EJERCICIO-01 · Hello Backend

## Qué he aprendido
He aprendido que un endpoint es una dirección a la que podemos pedir algo. En este caso, GET /hola llega al Controller y recibe una respuesta.

## Respuesta a la pregunta de comprensión
@Get() indica que este método responde cuando alguien hace una petición GET a la ruta del Controller.

## Qué he modificado
He cambiado el mensaje de respuesta, he añadido el curso DAM y he conservado la ruta GET /hola.

## Resultado
La API debe responder en http://localhost:3000/hola con un mensaje y el curso. Para probarla, ejecuta npm run start:dev desde backend/ y consulta la dirección en el navegador o con curl.
